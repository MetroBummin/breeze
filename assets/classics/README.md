# 고전 표지 갈아 끼우기

이 폴더의 `.jpg` 세 장이 서가에 걸리는 표지입니다. 파일을 갈아 끼우면
**권유 카드(받기 전)와 받은 책(서가) 둘 다** 바뀝니다. EPUB 은 손대지 않습니다.

| 파일 | 책 |
|---|---|
| `alice-in-wonderland.jpg` | Alice's Adventures in Wonderland |
| `the-great-gatsby.jpg` | The Great Gatsby |
| `odyssey.jpg` | The Odyssey |

이름은 정확히 이대로여야 합니다. `.epub` 파일 이름과 짝을 이룹니다.

## 크기

- 세로로 긴 책 표지 비율(2:3)이 가장 잘 맞습니다 — 카드가 세로로 깁니다.
- **가로 800px 안팎**이면 충분합니다. 카드는 그보다 훨씬 작게 그립니다.
- 한 장 **200KB 이하**. 세 장 모두 첫 화면에서 함께 받아 오니까요.
- `.jpg` 만 됩니다(`.png` 를 넣으려면 `classics.js` 의 `classicCoverFile` 도 함께 고쳐야 합니다).

## 이미 바뀐 뒤라면

이미 받아 둔 책의 표지는 그대로입니다 — 받을 때 한 번 씌우기 때문입니다.
새 표지를 지금 있는 책에도 씌우려면, 만드는 중이라면 개발자 도구 콘솔에서
한 줄이면 됩니다 —

```
refreshClassicCovers()
```

받아 둔 고전 전부의 표지를 이 폴더의 파일로 다시 씌웁니다. 새로고침도 필요
없습니다. (`scripts/library/classics.js`)

앱을 쓰는 사람 쪽에서는 둘 중 하나입니다:

- 책을 꾹 눌러 **정보 바꾸기 → 그림 파일에서 고르기**로 직접 넣거나,
- 그 책을 지우고 권유 카드에서 다시 받으면 됩니다.

## 어디서 구하나

세 권 다 1929년 이전 작품이라 **원본 표지는 퍼블릭 도메인**입니다.

- **Wikimedia Commons** — 초판 표지 스캔이 대부분 있습니다. 라이선스가
  `Public domain` 인지만 확인하세요.
- **Internet Archive / Project Gutenberg** — 스캔 원본.
- 새로 그린 표지(리커버, 영화 포스터, 출판사 디자인)는 **안 됩니다.**
  작품이 퍼블릭 도메인이어도 표지 디자인은 따로 저작권이 있습니다.

지금 들어 있는 개츠비 표지는 프랜시스 쿠갓의 1925년 초판 표지입니다.
