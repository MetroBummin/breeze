이 폴더에 넣으면 그대로 실립니다.
**안 넣어도 됩니다** — 없으면 글만 뜨고, 카드는 지금처럼 글자 표지가 됩니다.

## 고르는 기준

- **긴 변 1600px 안팎, 300KB 안팎.** 카드가 9:16 이라 세로로 긴 사진이 제일 잘
  맞습니다. 가로 사진이면 가운데가 잘리니 가운데에 중요한 것이 오게 고르세요.
- **진짜 JPEG 이어야 합니다.** 이름만 `.jpg` 로 바꾼 PNG 는 브라우저가 읽기는 하지만
  대여섯 배 무겁습니다. 맥이면 이 한 줄로 변환하면 됩니다 —

  ```
  sips -s format jpeg -s formatOptions 80 --resampleHeightWidthMax 1600 원본.png --out starship-1.jpg
  ```
- 이름은 표에 있는 그대로여야 합니다.
- **정말 자유롭게 쓸 수 있는 사진만.** 이 사진들은 앱과 함께 배포되고
  스토어 심사에도 같이 올라갑니다. 안전한 곳:
  - **NASA / SpaceX** — 스타십 사진은 여기가 정답입니다. SpaceX 의 Flickr 는
    CC0(퍼블릭 도메인), NASA 사진도 대체로 자유롭게 쓸 수 있습니다.
  - **Wikimedia Commons** — 라이선스가 사진마다 다르니 CC0 · CC BY 인지
    확인하고, CC BY 면 촬영자 이름을 이 파일 아래 "출처"에 적어 주세요.
  - **Unsplash · Pexels** — 인물 사진은 실존 인물과 무관한 스톡이라
    기사에 붙이면 안 됩니다. 풍경·사물에만 쓰세요.

뉴스 사이트에서 가져온 사진은 쓰지 마세요. 대부분 통신사(AP·Reuters·Getty)
사진이고, 앱에 실어 배포하는 것은 개인적으로 보는 것과 다릅니다.

## 사진을 넣은 뒤

파일만 넣으면 끝입니다. 다만 이미 앱을 한 번 연 기기에는 맛보기 글이 이미
들어가 있어서 다시 만들지 않습니다. 새 사진을 확인하려면 개발자 도구에서
`localStorage.removeItem('breeze.samples-seeded')` 를 실행하고, 서가에서 그
두 글을 지운 뒤 새로고침하세요.
