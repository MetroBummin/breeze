# Web-novel covers

These three covers are **original art made for Breeze** (movie-poster style).
They are **not** the authors' own cover art, and they are **not** generated by
the retired `tools/make-webnovel-covers.mjs`; they are supplied bytes verified
by exact sha256.

Each file is the same 768 × 1152 poster with the painted title and author
removed, so the art can sit under the UI title. The paths are the ones used by
`WEB_NOVELS[].cover` (`assets/webnovels/covers/${id}.webp`), so they render on
the 추천 (웹소설 tab) cards, the 내 책 cards, and the detail/preview page.

Alt text for each cover is **title + author**:

- `cinnamon-bun.webp` — Cinnamon Bun, RavensDagger
- `chasing-sunlight.webp` — Chasing Sunlight, InadvisablyCompelled
- `mr-penn.webp` — The Unexpected Engagement of the Marvelous Mr. Penn, R. K. Goff
