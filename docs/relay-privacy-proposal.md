# 책 자동 전송 개인정보 안내 수정안 — 아직 서비스에 적용하지 않음

적용 대상: `PRIVACY.md`, `SYNC.md`, 생성된 `docs/privacy.html` 및 실제 앱 동의 화면.
현재 운영 안내는 변경하지 않았다. 법률 검토를 마친 확정 고지가 아니라 기능 설명 초안이다.

## 사용자에게 제시할 문구

책 자동 전송에 동의하면, 같은 계정에서 안전하게 연결하고 승인한 기기 사이에서
없는 책 파일을 자동으로 전달합니다. 동의 범위는 기존 책과 앞으로 추가하는 책이며,
기기별 보내기·받기를 끌 수 있습니다. 동의 전에는 기존 책 전체를 업로드하지 않습니다.

책 파일과 제목·원본 파일명 등을 담은 전송 묶음은 기기에서 암호화한 뒤 Cloudflare R2의
비공개 임시 보관소로 전송됩니다. 서비스 서버는 책 평문이나 복호화 열쇠를 받지 않습니다.
로그인 이메일만으로 열쇠를 복원할 수 없으며, 기존 기기 연결이나 복구키가 따로 필요합니다.

지정 수신 기기 모두가 복호화·무결성 확인·기기 저장을 마치면 임시 파일 삭제를 즉시
시도합니다. 기본 접근 유효기간은 첫 업로드 권한 발급부터 24시간이며, 이 시간이 지나면
새 다운로드 권한을 발급하지 않습니다. 실제 삭제는 정리 작업·저장소 상태에 따라 늦어질
수 있어 정확히 24시간에 삭제된다고 보장하지 않습니다. 이미 발급된 짧은 접근 권한은
최대 60초 또는 전송 만료 시점 중 빠른 때까지 사용할 수 있습니다.

이는 영구 클라우드 백업이 아닙니다. 만료 후 원본을 가진 기기가 오프라인이면 기다리며,
사용 가능한 원본과 임시 사본을 모두 잃으면 서버에서 복구할 수 없습니다. 다른 사용자에게
책을 공유하거나 공개 링크를 제공하는 기능이 아닙니다.

서버에는 계정 식별자, 승인 기기의 공개 서명키·승인/동의 상태, 책의 불투명 식별값,
암호문 크기, 전송 시각·상태와 기기별 수신 상태를 처리합니다. 제목·본문·예문·원본 파일명·
원본 해시는 서버의 평문 상태나 객체 이름에 넣지 않습니다. 인증 요청은 Supabase로,
암호화 파일은 Cloudflare로 전달됩니다. 보관 국가/수탁사/문의 창구 등 실제 고지 항목은
배포 계정과 서비스 설정을 확인한 뒤 기존 개인정보처리방침에 정확히 반영해야 합니다.

## 실제 구현과 맞춰야 할 사항

현재 초안의 기술 보관기간: 요청 재사용 방지 기록 5분, 증분 이벤트 7일, 종료/유휴 파일
상태 최소 정리 기준 30일. 정리 작업이 중단되면 삭제가 늦어질 수 있다. 승인 기기 기록은
취소/계정 삭제 정책과 함께 처리한다. 앱 로그에는 토큰·서명 URL·책 내용·키를 남기지 않는다.
Cloudflare/Supabase 플랫폼 자체의 요청 로그·IP 처리·보존 설정은 배포 전에 별도로 확인한다.
