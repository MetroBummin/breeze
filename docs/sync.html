동기화

한 줄 요약

Breeze의 자동 동기화는 단어장과 마지막 읽던 자리를 기기 사이에 맞춥니다. 책 파일·본문·사진은 서버에 올리지 않습니다. 원문까지 옮기고 싶을 때만 사용자가 암호화 백업 파일을 직접 내보내고 불러옵니다.

처음 켤 때

  1. Sync에서 이메일 링크 또는 여섯 자리 코드로 로그인합니다.
  2. 첫 기기가 무작위 마스터 키와 복구키를 만듭니다.
  3. 복구키를 복사하거나 파일로 저장합니다. Breeze는 이 키를 다시 보여 주거나 서버에 보관하지 않습니다.
  4. 이후 단어장과 진행도는 자동 동기화됩니다.

새 기기는 복구키를 입력하거나, 기존 기기의 QR·여섯 자리 일회용 코드 승인을 받아 같은 보관함을 엽니다. 복구키와 기존 기기를 모두 잃으면 서버의 암호문을 열 수 없습니다.

표지를 Mac에서 바꿨다고 휴대폰 표지가 자동으로 바뀌지는 않습니다. 표지도 이미지 파일이므로 기기에만 두기 때문입니다. 원문·표지까지 다른 기기에 옮길 때는 아래의 백업을 사용합니다.

두 기기를 번갈아 읽을 때

  • 실제로 스크롤해 위치가 바뀔 때만 읽기 시간표가 갱신됩니다. 책을 잠깐 여는 것만으로 더 최근 위치가 되지는 않습니다.
  • 읽는 중에는 약 25초마다 위치를 보냅니다. 앱을 백그라운드로 보내거나 닫으면 마지막 위치를 바로 보냅니다.
  • 다른 기기에서 책을 열면 가장 최근에 실제로 읽은 위치부터 이어집니다. 더 멀리 읽은 퍼센트가 아니라 더 최근 기록이 기준입니다.
  • 두 기기에서 동시에 읽고 있다면 열린 화면을 강제로 다른 위치로 옮기지 않습니다. 다음에 나가거나 다시 열 때 마지막으로 저장한 위치가 다음 시작점이 됩니다.

같은 책을 두 기기에서 만났을 때

PDF·EPUB은 원본 파일 전체 SHA-256으로 같은 파일인지 확인합니다. ID가 다른 오래된 카드라도 원본 해시가 같으면 한 권으로 합칩니다.

원문까지 다른 기기로 옮기기

첫 동기화를 시작한 Mac에서 읽다가 iPhone으로 완전히 옮기고 싶다면 다음 순서입니다.

  1. Mac에서 지금 동기화가 끝날 때까지 기다립니다.
  2. Sync → 내 책·글 내보내기를 누릅니다.
  3. iPhone에서 같은 계정으로 로그인하고 복구키 또는 기존 기기 승인으로 보관함을 엽니다.
  4. Sync → 백업 파일 불러오기로 받은 .breeze.zip 파일을 선택합니다.

백업에는 책·글 본문, 원본 파일, 표지·삽화와 저장된 진행도가 기기에서 암호화된 채로 들어 있습니다. 같은 파일이 iPhone에 이미 있으면 중복 카드를 만들지 않고 한 권으로 합칩니다.

서버가 하지 않는 일

  • 책·기사의 본문 또는 표지·사진을 저장하거나 미리보기로 열지 않음
  • 사용자끼리 책을 전송하거나 공개 링크를 만들지 않음
  • 원문을 검색, AI 학습, 광고, 오디오북 변환에 쓰지 않음
  • 암호문을 사용자끼리 중복 제거하지 않음

암호화·복호화는 기기에서 이뤄집니다. 서버에는 계정 식별자, 암호문 크기·갱신 시각과 동기화에 필요한 기술 메타데이터만 남습니다. 자세한 법적·개인정보 처리 내용은 PRIVACY.md와 TERMS.md를 봐 주세요.
