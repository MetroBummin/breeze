동기화

한 줄 요약

Breeze는 같은 이메일로 로그인한 기기의 단어장만 자동으로 맞춥니다. 복구키나 기기 연결은 필요하지 않습니다. 책·글, 원본 파일, 사진, 읽던 위치는 각 기기에 남습니다.

사용 방법

  1. 설정에서 이메일 주소를 입력하고 메일의 링크 또는 여섯 자리 코드로 로그인합니다.
  2. 다른 기기에서도 같은 이메일로 로그인합니다.
  3. 저장한 단어와 뜻은 자동으로 합쳐집니다. 설정의 지금 동기화로 직접 다시 확인할 수도 있습니다.

오프라인에서 저장한 단어도 기기에 남아 있다가 다음 동기화 때 합쳐집니다. 두 기기가 동시에 단어를 바꾸면 더 최근 수정이 적용되고, 삭제 기록은 오래된 사본이 단어를 되살리지 않도록 함께 보관합니다.

무엇이 동기화되나

데이터자동 동기화저장 위치
저장한 단어·숙어, 뜻, 예문, 모르는 정도와 복습 정보예기기와 로그인 계정의 Supabase words 표
책·글 목록, 제목, 원본 PDF·EPUB·TXT, 본문·사진아니오각 기기
읽던 위치와 진행도아니오각 기기

단어장 데이터는 계정별 접근 제어(RLS)가 적용된 서버 행에 저장되며, 전송에는 HTTPS를 사용합니다. 새 방식의 단어장 행은 종단간 암호화된 보관함이 아니므로 서버 운영자가 내용에 접근할 수 있습니다.

이전 버전에서 옮기기

이전 버전의 암호화 보관함은 삭제하거나 덮어쓰지 않습니다. 보관함 열쇠가 남아 있는 기존 기기에서 같은 계정으로 한 번 동기화하면 이전 단어를 새 단어장으로 옮깁니다. 새 기기에서 먼저 로그인했는데 예전 단어가 보이지 않으면 기존 기기에서 앱을 열고 지금 동기화를 눌러 주세요. 기존 기기나 복구 가능한 열쇠가 전혀 없다면 이전 암호문만으로는 단어를 복원할 수 없습니다.

이전 서버에 저장된 책 메타데이터와 읽기 진행도 암호문은 보존하지만 현재 앱은 이를 새로 보내거나 적용하지 않습니다. 새 기기에서 책과 읽던 위치를 이어받는 기능은 현재 제공하지 않습니다.

실패했을 때

네트워크 오류나 저장 충돌이 나면 기기의 단어를 지우지 않고 다음 연결에서 다시 시도합니다. 동기화 상태와 마지막 성공 시각은 설정에서 확인할 수 있습니다.
