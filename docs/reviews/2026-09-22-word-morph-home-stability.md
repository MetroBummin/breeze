# 단어창 morph · 영영사전 · 홈 깜빡임

## 적용

단어 옆 mini pill이 같은 자리에서 상세 카드로 확장되고 다시 접힙니다. 본문은 어두워지거나 이동하지 않습니다. 선택한 단어 위/아래의 안전 공간을 기준으로 방향을 정하며, 최대 폭 360px·높이 380px 안에서 내용만 스크롤합니다. 화면 회전·키보드에 따른 visual viewport 변경도 반영합니다. 애니메이션 중 글자 자체는 확대하지 않고, 동작 줄이기 설정에서는 즉시 전환합니다.

한국어 뜻을 한 번만 표시하고, 다른 저장 뜻과 단어 관리 기능은 펼침 항목으로 정리했습니다. 별 선택과 영어 뜻은 바로 보이며, 예문은 두 줄 미리보기로 시작합니다. Reader 스크롤은 상세 창을 닫지만, 카드 내부 스크롤은 본문을 움직이지 않습니다.

## 영영사전 지연 원인

- 영어 정의 표시가 문맥 조회의 `loading`에 묶여 있어 이미 도착한 정의도 가려졌습니다. 영어 로딩/실패 상태를 독립시켰습니다.
- 저장된 단어는 영어 정의가 비어 있어도 보충 조회되지 않았습니다. 선택/확장 때 누락 정보를 보충합니다.
- 영영 데이터의 독립 캐시와 요청 공유가 없었습니다. 표제어별 동시 요청을 합치고 성공 30일·404 1일 캐시를 적용했습니다.
- 외부 요청은 시도당 3.5초 후 종료합니다. 통신 오류를 ‘없는 단어’로 저장하지 않고 재시도 버튼을 제공합니다. 최대 두 형태를 조회하며 숙어는 구성 단어로 대신하지 않습니다.

[Free Dictionary API](https://dictionaryapi.dev/)만 사용하며 영영사전용 AI 요청은 추가하지 않았습니다. 이번 환경에서 stigma/patient/take 직접 요청은 각각 8초 제한까지 응답이 없었습니다. 외부 API/네트워크 지연 자체가 해소됐다는 증거는 없으며, 앱의 중복 대기와 무한 로딩을 제거한 것입니다. 자동 검증의 성공·지연·실패 응답은 제어된 fixture입니다.

## 홈 깜빡임 원인

`renderAllBookViews`가 호출될 때 Home이 카드 전체를 제거·재생성하면서, 같은 표지에도 새 이미지와 Blob URL을 만들었습니다. RSS도 기존 카드를 먼저 제거하고 이미지를 기다렸습니다. 동기화·진행률 갱신이 실제 페이지 새로고침처럼 보일 수 있는 구조였습니다. 자동 페이지 reload를 원인으로 확인한 것은 아닙니다.

이제 ID와 표시 내용이 같은 카드는 노드·이미지·URL을 유지하고 진행률만 갱신합니다. 변경된 RSS 묶음도 새 사진이 준비된 뒤 교체합니다. Reader→Home 전환의 홈 배경 투명도 애니메이션을 없애, 이동 중 빈 바탕이 드러나지 않도록 했습니다.

## 후속 디자인 및 사전 교체

단어 관리와 접기 버튼을 제거했습니다. 제목·삭제·발음은 함께 스크롤하며, 제목 23px와 액션 높이 36px를 가운데 정렬했습니다. 색칠 스위치는 42×26px, 터치 높이는 44px입니다. 선택된 별에만 기존 단계 색을 낮은 채도로 적용하고, 영어 재시도는 접근성 이름이 있는 아이콘으로 바꿨습니다.

기존 dictionaryapi.dev는 bank 요청에도 10초간 응답하지 않았습니다. FreeDictionaryAPI.com의 bank 요청은 HTTP 200/약 0.97초였습니다. 공급자를 교체한 뒤 실제 브라우저에서 patient 영어 정의 4개 표시를 Chromium 935ms/WebKit 1164ms에 확인했습니다. 이는 한 번의 관측이며 성능 보장은 아닙니다. AI는 추가하지 않았고, 번역 데이터도 요청하지 않습니다. 출처와 CC BY-SA 링크를 정의 아래 및 배포 랜딩 페이지에 표시합니다.

## 배포 전 홈 복귀 깜빡임 추가 수정

실제 View Transition에서 닫기 애니메이션을 379ms/381ms에 검사했을 때 old(root) opacity가 0.0000036에서 1로 복귀했습니다. 원인은 CSS animation shorthand의 기본 fill-mode none이었습니다. 종료된 리더 스냅샷이 제거되기 직전 원래 모습으로 돌아왔습니다. 열기/닫기에 fill-mode both를 지정하고, 닫기 duration 직후 opacity 0 유지 회귀 검증을 추가했습니다.
