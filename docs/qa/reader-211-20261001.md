# Breeze 1.6 (211)

Base: build 210, `bf995ea`. Includes the original commit ancestry of onboarding
PR #62. App and share-extension marketing versions remain 1.6 and build numbers
are both 211.

## Changes and evidence

- Horizontal PDF progress counts the visible page and its own scroll range,
  excluding deleted pages. Browser cases cover pages 1/6/11/12, portrait and
  landscape viewports, full-page visibility, tall paper, zoom and saved progress.
- Eraser repaint no longer detaches all unchanged SVG children. The 80-stroke
  fixture plus a highlight records 162 unnecessary detachments on build 210 and
  zero with the fix. Partial erase, opacity groups, cancellation, history and
  storage remain covered by production-input tests.
- Home/Reader keeps the connected title capsule and replaces animated full-screen
  clipping with translation/opacity. No new timers or animation coordinator.
  Unchanged book nodes and reading positions survive round trips.
- EPUB preview viewports are limited to one slice instead of the whole chapter.
  Pages 43/44/45 in a constructed 1,000-paragraph EPUB have checked source offsets
  and actual colored screenshot pixels in Chromium and WebKit. Source frames
  also release their old height floor once per width change: wider reflow must
  shrink the chapter rather than retain blank tail pages.
- Reviewed onboarding guidance, disabled Back/restoration, Skip, replay, real
  word/sentence/Aa actions and personal-data isolation. Generated asset conflicts
  with build 210 were resolved by restamping from current source.

## Validation

Local tests: `npm test`, Home UI, Reader reuse, onboarding, PDF ink, PDF pinch,
Reader work, Breeze 1.6 navigation/deletion/rotation, word morph and design-tone
checks. The new `verify-reader-211-browser.mjs` runs in both Chromium and WebKit
and is included in CI. Responsive checks cover phone/tablet/desktop/short
viewports in both themes. Capacitor `ios:sync` prepares 121 bundled files.

Two existing browser test assumptions were corrected, without widening product
assertions: sidebar reflow waits for its actual anchor remapping; thumbnail
geometry compares the original paper ratio instead of rounded bitmap dimensions
(e.g. 792:612 paper uses a 145x113 pixel backing store). Onboarding replay waits
for boot and the settings entrance animation before issuing a synthetic tap.

These results establish browser behavior and removed work, not physical iPad
latency. The user's original EPUB was not supplied. Archive/upload status must
be obtained from the Xcode Cloud run on the merged commit; this document does
not claim that browser tests constitute a signed archive or Apple delivery.
