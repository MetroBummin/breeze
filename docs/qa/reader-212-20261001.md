# Reader input release 1.6 (212)

Base: build 211, main `b8373c7ec35bf94f2e6664d444d846c0c614f9ab`.

## Root causes and changes

- Horizontal PDF settings queued a swipe/arrow hint which appeared after Aa
  closed. Remove that redundant notice. Necessary Reader notices now occupy one
  actual title slot rather than hard-coded offsets over the whole pill. The
  title yields before first paint; the title button owns the complete slot;
  notice show/hide never resizes control targets. Writing and sentence waiting
  hide the copy slot together. Queue and lookup/input priority are retained.
- EPUB chapter geometry updates replaced the entire thumbnail track, removing
  a pressed button before its click. Defer layout/virtualization until that
  contact finishes, then apply pending work after the click. Preview creation
  also yields while the user presses the list. No touch is cancelled/captured.
- EPUB selection previously jumped instantly; one 200ms movement now settles at
  the requested source slice. A newer selection supersedes old movement, direct
  scroll interrupts it, and reduced motion is immediate. Clear obsolete pending
  source restoration. WebKit truncates fractional CSS scroll offsets: tolerate
  one CSS pixel at page boundaries so the previous page does not remain selected.

## Before/after evidence

The new regressions fail on an isolated 211 worktree: deferred horizontal
instruction appears after closing Aa, and a trusted mouse down/up across a late
chapter-height change loses the pressed EPUB button. With 212, touchscreen
Aa/mode/compact notice taps and repeated EPUB selections pass in Chromium and
WebKit at 320/390/820/1440px and a short 844x390 viewport, light and dark.

EPUB tests also sample intermediate monotonic motion, exact source alignment,
latest-selection wins and reduced motion. The complete status text remains in a
plain-text polite live region. No notice rewrites a book title or action handler.

## Existing verification

`npm test` passed; the typecheck baseline remains 34 diagnostics. Existing Reader
notification FIFO/priority/expiry tests passed in both engines. Reader work,
shared-control geometry/motion and final CI are checked before merging. The Reader
work test now waits for deferred bookmark-list rendering and page-move completion
rather than expecting all DOM work in the click handler. Capacitor preparation and
Xcode Cloud run evidence are recorded in the release PR after completion.

## EPUB deletion

EPUB thumbnail pages are layout slices, not fixed publisher pages. This release
fixes navigation and retains the existing absence of page deletion. A future
persistent deletion feature needs a source paragraph/range or chapter contract;
transient viewport page numbers are unsuitable for storage identifiers.

Browser evidence does not establish physical iPad latency or reproduce the
user's exact EPUB file. Apple archive and final Connect processing are separate
from the browser checks.
