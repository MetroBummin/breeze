# File-import feedback and active shelf — 2026-09-26

Base: `9ce0004d91af43c2d0cdb1ee249f880530868a9b`.

## Observed failure and scope

The user confirmed a PDF appeared and opened immediately from Home while old
1/20/40-page progress notices continued playing. The Long-form shelf also stayed
stale because normal file addition called `renderHome()` instead of refreshing
the visible shelf. This is a presentation regression, not evidence of increased
PDF parsing time.

Each file-add or original-reconnection operation now owns one replaceable notice
slot. Progress replaces the current status; terminal success/failure/duplicate
feedback closes it. Input and overlays retain priority. Navigation invalidates
old presentation without cancelling the import. A completed import refreshes the
currently visible shelf using the existing `renderAllBookViews()` helper.
Partial original-file-storage warnings are reported only after the book write
succeeds. No original/paragraph/identity schema or parser algorithm changes.

Production changes are limited to `scripts/ui/reader-notifications.js`,
`scripts/importers/importers.js` (progress callback only), and
`scripts/library/library.js`. Asset versions are generated by the existing
stamper. PDF ink, geometry, momentum/touch, lookup, native project and dormant
Share Extension are unchanged.
