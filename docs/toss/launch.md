# 출시 문구

콘솔에 넣는 문구입니다. 앱 아이디는 `breeze`로 두고, 사용자에게 보이는 이름은 아래에서 고릅니다.

## 앱 이름 제안

1. 브리즈 고전
2. 브리즈 읽기
3. 고전 읽기

짧은 이름 제한에 걸리면 `브리즈 고전`을 먼저 검토합니다. 토스 로고나 토스 이름은 넣지 않습니다.

## 한 줄 소개

영어 고전을 읽고, 모르는 단어를 눌러 뜻을 모아요.

## 상세 설명

브리즈 고전은 영어 고전을 읽는 미니앱입니다. 셜록 홈즈와 공개된 고전을 앱 안에서 읽고, 모르는 단어를 누르면 그 문맥의 뜻을 보여 줍니다. 저장한 단어는 단어장에서 다시 볼 수 있습니다.

단어와 읽던 위치는 이 미니앱 안에 저장됩니다. 로그인, 파일 가져오기, 다른 사이트로 나가는 링크는 없습니다.

뜻을 만들 때 인공지능을 사용합니다. 인공지능이 만든 뜻에는 AI 표시가 붙고, 처음 볼 때 안내가 나옵니다.

## 카테고리

교육.

교육 카테고리에서는 국가전문자격이나 국가기술자격이 없는 상태에서 수익이 나는 서비스를 출시할 수 없습니다. 이 미니앱은 무료이고 인앱 결제와 광고가 없습니다. 무료이면 이 조항을 만족합니다. 유료 기능이나 광고를 더하면 자격이 없는 한 출시할 수 없습니다.

## 키워드

영어, 고전, 읽기, 단어장, 셜록홈즈, 단어, 학습

## 아이콘

콘솔 로고는 PNG, 가로 600px, 세로 600px, 정사각형, 배경이 불투명해야 합니다. 파일에 모서리 둥글기를 미리 넣지 않습니다. 콘솔이 모서리를 깎습니다. 토스 자산과 사람 얼굴을 넣지 않습니다.

현재 `assets/favicon/icon-512.png`는 512×512, RGB, 불투명입니다. 600×600이 아니므로 콘솔 로고로 쓸 수 없습니다. 소유자가 같은 마크를 600×600 정사각, 불투명 배경, 모서리 마스크 없는 PNG로 보내야 합니다. 상태: needs-owner.

## 스크린샷

콘솔 권장 크기는 세로 636×1048 PNG 3장 이상, 가로 1504×741 PNG 1장 이상입니다. 1932×828 썸네일은 게임용입니다.

라이트 모드 세로 3장을 `docs/toss/screenshots/`에 넣어 두었습니다.

1. `01-home-classics.png` — 고전 서가. 가져오기 단추와 기사 전환은 없습니다.
2. `02-reader.png` — 셜록 홈즈 「The Adventure of the Speckled Band」 본문.
3. `03-vocabulary.png` — 단어장. 저장한 단어가 없을 때의 안내입니다.

다시 만들려면:

```bash
npm run toss
node tools/capture-toss-screens.mjs
```

스크립트는 `toss/dist`를 로컬에서 열고, 뷰포트 636×1048, 라이트 모드로 위 세 장을 저장합니다. 로그인, 가져오기, 외부 사이트는 열지 않습니다. 가로 스크린샷은 콘솔 제출 전에 소유자가 같은 화면으로 1504×741을 추가하면 됩니다. 상태: 세로는 스크립트로 생성, 가로는 needs-owner.
