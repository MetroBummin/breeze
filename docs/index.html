Breeze

문서 페이지: https://breeze.io.kr/docs/ 이 문서는 앱의 현재 동작을 기준으로 씁니다. 다음에 만들 기능은 ROADMAP.md에, 데이터 처리 방식은 PRIVACY.md에 따로 적습니다.

Breeze는 영어 글을 읽다가 모르는 낱말을 바로 확인하고, 내 단어장으로 가져가는 개인 리더입니다. PDF·EPUB 파일, 붙여 넣은 글, 조건이 맞는 기사 URL을 읽을 수 있습니다.

지금 할 수 있는 것

  • Books에는 PDF·EPUB을, Casuals에는 붙여 넣은 글과 기사 URL을 넣습니다. 각 줄은 마지막으로 읽던 항목을 따로 기억합니다.
  • PDF·EPUB은 글자와 원본을 오갈 수 있습니다. PDF 원본은 오른쪽 위의 − / +로만 확대합니다. 핀치 확대는 iOS 홈 화면 웹앱에서 브라우저가 스크롤 위치를 다시 계산하면서 페이지가 튀는 문제가 있어 의도적으로 쓰지 않습니다.
  • Aa는 글자 모드의 글자 크기·여백·테마를 바꿉니다. EPUB과 글자 모드에는 PDF 배율이 적용되지 않습니다.
  • 읽는 중 상단바는 사라져도 파란 진행 줄은 화면 위에 남습니다. 오른쪽 아래의 Aa, 원본/글자 단추는 읽는 동안 옅어지지만 자리는 고정입니다.
  • 낱말을 누르면 문맥에 맞는 뜻을 보고, 뜻을 고쳐 단어장에 넣을 수 있습니다. 같은 문맥으로 다시 누른 답은 기기에서 바로 엽니다. 문장 전체 설명은 로그인 후 하루 5번까지입니다.
  • 로그인은 선택입니다. 로그인하면 단어장·읽던 자리를 기기 사이에 암호화해 맞춥니다. 원문·표지·사진은 자동으로 보내지 않습니다. 자세한 범위는 SYNC.md를 봐 주세요.

원본 파일과 동기화

원본 PDF/EPUB 파일과 표지·삽화는 현재 기기에만 저장합니다. 서버에는 단어장, 위치, 제목과 파일 식별값 같은 작은 기록만 동기화합니다. 다른 기기에서 원본 모드까지 그대로 읽고 싶다면 설정 → 다른 기기와 연결하기의 암호화 백업 파일을 한 번 불러옵니다.

파일을 다시 연결하거나 백업을 불러올 때는 원본 파일 전체 SHA-256으로 같은 파일인지 확인합니다. 원본 파일 Blob을 서버에 올리는 계획은 없습니다.

DRM EPUB과 스캔 PDF의 텍스트 선택·단어 클릭·OCR은 지원하지 않습니다. 스캔 PDF는 원본 화면으로 읽을 수 있습니다.

기사 URL

URL 가져오기는 공개적으로 접근 가능한 페이지에서 본문과 사진을 골라 내는 편의 기능입니다. 로그인·결제·사이트 정책 때문에 읽을 수 없는 페이지는 가져오지 않습니다. 가져온 글은 사용자가 읽을 권리가 있는 내용에만 사용해야 하며, 유료 기사 우회나 사이트 안에 Breeze를 주입하는 기능은 제품 범위에 두지 않습니다.

개인정보과 보안의 현재 상태

  • 로그인 전 책·단어장·진행도는 기기에만 있습니다. 단, URL 가져오기는 CORS 때문에 Breeze의 중계 서버에 해당 URL을 요청합니다.
  • 로그인하면 단어·예문·복습 기록과 읽던 위치만 기기에서 종단간 암호화(E2EE)되어 자동 동기화됩니다. PDF·EPUB·기사 본문·사진은 서버에 올라가지 않습니다.
  • 복구키나 기존 기기의 승인이 없으면 Breeze도 암호문을 열 수 없습니다. 자세한 범위는 PRIVACY.md에 적습니다.
