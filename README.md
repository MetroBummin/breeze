# Breeze Refactored

기존 `breeze/index.html` 단일 파일을 기능별 파일로 분리한 버전입니다.
원본 프로젝트는 수정하지 않았습니다.

## 주요 변경

- 목차 버튼과 목차 시트를 화면에서 제거했습니다.
- 목차 및 전권 AI 정리 로직은 `legacy/`에 전부 주석 처리해 보관했습니다.
- CSS를 화면 책임별로 5개 파일로 분리했습니다.
- JavaScript를 저장소, 라이브러리, 반입기, 사전, 리더, 설정, 동기화로 분리했습니다.
- 문서의 EPUB/PDF 조판 신호는 목차가 아니라 읽기 화면 포맷에만 사용합니다.
- 이전 버전의 `book.tidy.blocks` 데이터는 읽기 호환성을 위해 표시만 지원합니다.
- IndexedDB 이미지 이름 변경 완료 대기, 책 삭제 tombstone, Supabase 삭제 오류 처리를 정리했습니다.
- 동일한 책을 다른 파서 버전으로 넣어도 내용 지문으로 서버 사본을 찾습니다.
- 로그인한 사용자는 동의 후 책 전체의 디자인을 기기에서 분석하고, 제목·목차·인용문 후보만 AI로 판정합니다. 일반 본문은 전송하지 않습니다.

## AI 조판 함수

Supabase Edge Functions에 `format`이라는 이름으로 `server/format/index.ts`를 배포합니다.
기존 `dict` 함수와 같은 `GEMINI_API_KEY` 또는 `ANTHROPIC_API_KEY`, 선택적으로 `AI_PROVIDER`를 사용합니다.
GitHub Pages 배포만으로 Edge Function이 자동 배포되지는 않습니다.

책은 PDF/EPUB 위치·글꼴 단서로 만든 기본판으로 즉시 열립니다. 사용자가 AI 조판에 동의하면 기기가 전권 디자인 문법을 만든 뒤, 구조가 의심되는 후보만 최대 55,000자까지 AI 공급자에게 전송합니다.
일반 본문은 기본값이라 보내지 않으며, AI도 본문 결과와 설명을 생략하고 확신하는 `h1/h2/h3/quote/note/toc` 위치만 돌려줍니다.
모든 후보 묶음이 서버와 브라우저의 안전 검사를 통과해야 완성 지도로 저장됩니다. 읽고 있는 화면은 다시 그리지 않고 다음에 책을 열 때 한 번에 적용합니다.
넓은 자간은 PDF 글자 좌표로 화면용 문자열만 복원하며, 저장된 원문 배열은 변경하지 않습니다.

## 실행

정적 파일 서버에서 이 폴더를 열면 됩니다. `file://`로 직접 열면 브라우저의 파일·네트워크 정책 때문에 PDF/EPUB 기능이 제한될 수 있습니다.

```bash
python3 -m http.server 8765
```

그 뒤 `http://127.0.0.1:8765/`를 엽니다.
