# Breeze Refactored

기존 `breeze/index.html` 단일 파일을 기능별 파일로 분리한 버전입니다.
원본 프로젝트는 수정하지 않았습니다.

## 주요 변경

- 목차 버튼과 목차 시트를 화면에서 제거했습니다.
- 목차 및 전권 AI 정리 로직은 `legacy/`에 전부 주석 처리해 보관했습니다.
- CSS를 화면 책임별로 5개 파일로 분리했습니다.
- JavaScript를 저장소, 라이브러리, 반입기, 사전, 리더, 설정, 동기화로 분리했습니다.
- 문서의 EPUB/PDF 조판 신호는 목차가 아니라 읽기 화면 포맷에만 사용합니다.
- 이전 버전의 `book.tidy.blocks` 데이터는 읽기 호환성을 위해 표시만 지원합니다.
- IndexedDB 이미지 이름 변경 완료 대기, 책 삭제 tombstone, Supabase 삭제 오류 처리를 정리했습니다.

## 실행

정적 파일 서버에서 이 폴더를 열면 됩니다. `file://`로 직접 열면 브라우저의 파일·네트워크 정책 때문에 PDF/EPUB 기능이 제한될 수 있습니다.

```bash
python3 -m http.server 8765
```

그 뒤 `http://127.0.0.1:8765/`를 엽니다.

## 확인

Node.js가 있으면 외부 패키지 없이 구조 검사를 실행할 수 있습니다.

```bash
npm test
```
