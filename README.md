# Breeze Refactored

기존 `breeze/index.html` 단일 파일을 기능별 파일로 분리한 버전입니다.
원본 프로젝트는 수정하지 않았습니다.

읽을거리를 파일에만 의존하지 않도록 방향을 넓히는 중입니다 — [ROADMAP.md](ROADMAP.md).

- 상단바의 붙여넣기 버튼으로 기사·X 스레드·뉴스레터 등 **아무 영어 글이나 바로** 읽기 화면에 올립니다. 첫 줄이 제목, 빈 줄이 문단 경계, 빈 줄 없이 줄만 바꾸면 줄마다 카드가 됩니다. 넣는 순간부터 오프라인에서 읽힙니다.

## 주요 구조

- 목차 버튼과 목차 시트를 화면에서 제거했습니다.
- CSS를 화면 책임별로 5개 파일로 분리했습니다.
- JavaScript를 저장소, 라이브러리, 반입기, 사전, 리더, 설정, 동기화로 분리했습니다.
- PDF와 EPUB은 `원본`과 `글자` 모드를 자유롭게 전환할 수 있습니다.
- 원본 파일은 별도 IndexedDB 저장소에 보관하며 서버 책 동기화에 포함하지 않습니다.
- 글자 문단마다 원본 PDF 페이지·페이지 내부 위치 또는 EPUB 장·요소 위치를 연결합니다.
- PDF 원본은 PDF.js 캔버스와 페이지 비율 단어 좌표 지도를 사용합니다. 단어를 한 번 누르면 같은 좌표로 사전과 하이라이트가 열려, 패널이 생겨 페이지 폭이 바뀌어도 범위가 밀리지 않습니다.
- 글자를 하나씩 따로 넘겨주는 PDF도 같은 기준선끼리 되붙여 진짜 단어로 읽습니다. 예전에는 낱글자가 단어가 되어 저장한 `h`가 온 페이지에 밑줄을 그었습니다.
- 원본 위치 지도는 걸러낸 페이지를 뺀 순번이 아니라 실제 PDF 페이지 번호를 씁니다. 이미 넣어 둔 책은 같은 파일을 한 번 더 끌어다 놓으면 지도만 새로 만들고 진행도와 단어장은 그대로 둡니다.
- 사전 패널이 열리고 닫혀 읽는 폭이 바뀌어도 보던 줄이 제자리에 남습니다.
- EPUB 원본은 스크립트와 위험 요소를 제거한 뒤 샌드박스 안에서 출판사 스타일을 표시합니다.
- 글자 모드는 문서 자체의 확실한 구조 단서만 반영하고, 애매한 부분은 평범한 본문으로 둡니다.
- 전권 AI 조판 클라이언트·서버 함수·캐시는 제거했습니다. 문맥 사전 AI는 별도 기능이라 유지합니다.
- IndexedDB 이미지 이름 변경 완료 대기, 책 삭제 tombstone, Supabase 삭제 재시도와 겹친 동기화 요청 처리를 정리했습니다.
- 동일한 책을 다른 파서 버전으로 넣어도 내용 지문으로 서버 사본을 찾습니다.

## 원본 파일과 동기화

- 새 PDF/EPUB은 반입할 때 원본 Blob과 추출된 글자를 서로 다른 로컬 저장소에 넣습니다.
- 서버 책 동기화에는 추출된 글자, 보수적인 블록 정보, 작은 위치 지도, 파일 형식 메타데이터만 포함됩니다.
- 다른 기기에서 서버 책을 받은 뒤 원본 모드를 쓰려면 같은 원본 파일을 한 번 다시 연결해야 합니다.
- 기존 책도 원본 모드에서 파일을 다시 고르면 내용 지문을 검사한 뒤 진행도와 단어장을 유지합니다.
- 예전 책 ID로 저장된 원본도 파일 해시로 다시 찾아 현재 책 ID에 연결하며, 읽는 중에는 서버 삭제 표시가 로컬 원본을 지우지 않습니다.
- 진행도는 서로 다른 화면 높이를 섞지 않고 PDF 페이지·EPUB 장·글자 문단의 논리적 위치로 계산합니다.
- DRM EPUB과 스캔 PDF의 단어 클릭/OCR은 지원하지 않습니다. 스캔 PDF는 원본 화면으로 읽을 수 있습니다.

## 실행

정적 파일 서버에서 이 폴더를 열면 됩니다. `file://`로 직접 열면 브라우저의 파일·네트워크 정책 때문에 PDF/EPUB 기능이 제한될 수 있습니다.

```bash
python3 -m http.server 8765
```

그 뒤 `http://127.0.0.1:8765/`를 엽니다.

